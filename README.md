# Cataract Grading Dataset

## Description

This repository contains information and resources associated with our
cataract grading research.

## Dataset

The complete dataset is available through the following data repository:

(https://doi.org/10.5281/zenodo.23003144)

## Dataset Contents

- Cataract images
- Cataract grading labels
- Dataset description

## Purpose

The dataset was used for research on automated cataract grading.
